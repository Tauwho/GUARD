# Interfaces between streams (frozen at Phase 0)

Every place where one stream's output is another stream's input. Each has a frozen spec, a mock or fixture the consumer builds against, a contract test, and a flag that swaps mock for real. Changes are additive only (see `contracts/ext/README.md`); `tools/check_contract_compat.py` blocks anything else.

Direction is always **producer -> main -> consumer**. Nobody hands work to a person.

| ID | Interface | Producer | Consumer(s) | Frozen spec | Mock / fixture on main | Contract test | Mock -> real switch |
|---|---|---|---|---|---|---|---|
| I1 | Wire messages C1-C7 (POD structs, codecs) | A (`core/include/guard/types.hpp`, `codec.hpp`) | B (QNX processes) | `contracts/messages.md` @ `contracts-v1.2`; `contracts/fixtures/messages/*.json` | The fixtures themselves | Generated byte-exact codec tests (ctest) | n/a (same code on host and target) |

| I3 | Reason codes C10 | P (frozen) | A, B, P | `contracts/reason_codes.yaml` | Generated `reason_codes.hpp` | `schemas` policy check; compat check forbids renumbering | n/a |
| I4 | Scenario C11, config C12 | A (`scenarios/*.yaml`) | B (target runner, image), P (demo) | `contracts/scenario.schema.json`, `config.schema.json` | `scenarios/F0-F8.yaml` | `schemas` check; invariant: B2 `forbidden_reasons` for SIM_CONTACT and SIM_ZONE_BREACH never removed (`check_contract_compat.py --scenario-invariants`) | n/a |

## Not interfaces any more (removed by D26)
- C1 `RouteProposal` (v1.3, D24): cut. `guard-planner` checks a route with `guard::check_route` and emits ordinary C1 `Proposal`s.
- Any human review, approval, `CONTRACT-Q:` or `PO-DECISION:` between streams.
